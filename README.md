# Bluestock Fintech — Mutual Fund Analytics Platform

> End-to-end data pipeline, database, EDA, performance metrics, and advanced analytics
> for Indian mutual fund data (2022–2026).

---

## Project Overview

This capstone project builds a complete mutual fund analytics platform covering:

| Layer | What it does |
|-------|-------------|
| **Data Generation** | 10 synthetic CSVs (12,000+ NAV rows, 50,000 transactions, 2,000 investors) |
| **Live NAV Fetch** | Real-time NAV from AMFI API (`mfapi.in`) for 6 scheme codes |
| **Data Cleaning** | Forward-fill, deduplication, KYC flagging, SEBI TER cap enforcement |
| **SQL Database** | SQLite star schema — 9 tables, 86,000+ rows loaded via SQLAlchemy |
| **EDA** | 15 charts: NAV trends, AUM growth, SIP milestones, geographic heatmaps, correlation matrix |
| **Performance Metrics** | CAGR, Sharpe, Sortino, Alpha/Beta (OLS), max drawdown, composite scorecard |
| **Advanced Analytics** | VaR/CVaR, rolling Sharpe, cohort analysis, SIP continuity flagging, HHI, recommender |

## Database Schema (Star Schema)

```
dim_fund          ← dimension: 10 funds
dim_investor      ← dimension: 2,000 investors
fact_nav          ← 12,200 daily NAV records
fact_transactions ← 50,000 investor transactions
fact_performance  ← 40 annual performance records
fact_aum          ← 560 monthly AUM snapshots
fact_sip          ← 800 SIP mandates
fact_holdings     ← 1,260 quarterly sector allocations
fact_benchmark    ← 9,760 benchmark daily returns
```

## Setup & Run

### Prerequisites
```bash
python3 --version   # 3.10+
pip3 install pandas numpy scipy sqlalchemy matplotlib seaborn jupyter nbconvert requests openpyxl
```

### Run full pipeline (in order)

```bash
# Step 0 – Generate synthetic data
python3 scripts/generate_mock_data.py

# Step 1 – Data ingestion + quality report
python3 scripts/data_ingestion.py

# Step 2 – Live NAV fetch from AMFI API
python3 scripts/live_nav_fetch.py

# Step 3 – Clean data
python3 scripts/clean_data.py

# Step 4 – Load SQLite database
python3 scripts/load_db.py

# Step 5 – Run 10 SQL queries
python3 scripts/run_queries.py

# Step 6 – EDA notebook (generates + executes)
python3 scripts/generate_eda_notebook.py
python3 -m jupyter nbconvert --to notebook --execute --inplace \
        --ExecutePreprocessor.timeout=180 notebooks/03_eda_analysis.ipynb

# Step 7 – Performance metrics
python3 scripts/compute_metrics.py

# Step 8 – Advanced analytics notebook
python3 scripts/generate_advanced_notebook.py
python3 -m jupyter nbconvert --to notebook --execute --inplace \
        --ExecutePreprocessor.timeout=180 notebooks/05_advanced_analytics.ipynb
```
